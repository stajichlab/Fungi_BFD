# Overwritten per-task by FUNANNOTATE_TRAIN/UPDATE main.nf: MYSQLSERVER=127.0.0.1:${PORT}.
# 127.0.0.1, not the node hostname -- mariadbd is bound to loopback only
# (see my.cnf bind-address) and PASA runs on the same node/namespace, so
# there is never a reason for this connection to leave loopback. Routing it
# through the node's real hostname instead round-trips over the cluster
# network fabric and made MariaDB's host-ACL check reject the connection
# (reverse-DNS resolved the peer to the InfiniBand FQDN, which matched none
# of the ACL entries mariadb-install-db creates) -- confirmed 2026-09-09
# debugging Beauveria_bassiana_MBC_034's FUNANNOTATE_TRAIN failure.

# killed at task end. There is no persistent data behind it and nothing
# outside this one task can ever reach it, so there is nothing this
